# Historical test2017 evaluation configuration extracts

These files were read from the researcher's original E2/VLM evaluation output directories and sanitized before publication.
All local machine paths and credential-like keys have been replaced with placeholders. **These files are not directly runnable** without restoring appropriate local model and dataset paths.

They document the related VLM evaluation pathways; they must **not** be described as a complete configuration archive of the E16 full-2,416 evaluation or every E2-A/B/D run. Additional scripts/predictions may be needed for full metric reproduction.
